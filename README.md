# Project Management App

Ứng dụng quản lý dự án học tập theo mô hình Project-Based Learning.

## Tech Stack

### Backend
- ASP.NET Core
- Entity Framework Core
- MySQL (XAMPP)
- JWT Authentication

### Frontend
- React
- Vite
- JavaScript

## Project Structure

├── frontend
│ ├── src
│ ├── public
│ └── package.json
└── README.md
